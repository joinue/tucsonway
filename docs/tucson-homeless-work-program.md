# Tucson Homeless Work Program (HWP)

The purpose of the Tucson Homeless Work Program is to give people residing in an emergency shelter a **pathway out of homelessness through work, community collaboration, and navigation of existing services**.

The program is designed to:
- Build trust with people experiencing homelessness
- Move them from temporary housing options to more permanent housing

> **Important:** The Tucson Homeless Work Program is **not a government program**. It is a collaboration of multiple nonprofit, healthcare, faith-based, and philanthropic organizations.
