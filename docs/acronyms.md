# Commonly Used Acronyms — Homeless Services (Tucson/Pima County)

Glossary of acronyms used by Tucson Pima Collaboration to End Homelessness (TPCH) and partner agencies. *Source: TPCH, updated 10/19/2018 — terms with notable changes since then are flagged.*

## A

| Acronym | Meaning |
|---------|---------|
| ACA | Affordable Care Act (a.k.a. "Obama Care") |
| ADA | Americans with Disabilities Act |
| ADC (or DoC) | Arizona Department of Corrections |
| ADOH | Arizona Department of Housing |
| AFH | Assessment of Fair Housing |
| AFSC | American Friends Service Committee |
| AHAR | Annual Homeless Assessment Report to Congress |
| AHCCCS | Arizona Health Care Cost Containment System *(pronounced "Access")* — Arizona's Medicaid |
| AIDS | Acquired Immune Deficiency Syndrome (caused by HIV) |
| APR | Annual Performance Report |
| ARC | American Red Cross |
| AZHC | Arizona Housing Coalition (merger of AZCEH + Arizona Housing Alliance) |
