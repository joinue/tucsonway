# TPCH "Need Help?" Guide — 2026 Edition (Updated December 2025)

**This is the most current TPCH resource directory for people experiencing homelessness or at risk of homelessness within 14 days in Tucson and Pima County.** Bilingual (English/Spanish). Where this conflicts with earlier docs in this folder, **this guide is the source of truth.**

> **Important system update:** All 520 numbers must now be **dialed with the area code** even when calling locally.
