# Pima Council On Aging (PCOA)

PCOA currently has funds for **homelessness prevention for older adults**.

## Eligibility

One-time support for adults who are:

- **Age 60+**
- Need help covering one or more of: **rent, mortgage, move-in costs, utilities, property taxes**
- Able to sustainably cover their own bills moving forward (i.e., this is a one-time stabilizer, not ongoing assistance)

## How to Apply

1. **Call the PCOA Helpline** for an initial screening: **520.790.7262**
2. Providers and individuals can also use the web portal — **Referrals to PCOA** at **pcoa.org**
